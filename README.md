# 代写小助手 🐋

一个轻量小工具：**读取 TXT 文档，把内容通过键盘自动输入到任意输入框里**。
适合用来快速录入重复性文字、把草稿打到表单/编辑器中等场景。

## 功能

- ✅ 读取 `.txt` 文档（自动识别 UTF-8 / GB18030 / Big5 编码）
- ✅ 键盘逐字输入（支持中文、emoji，基于 Win32 `SendInput`，无需管理员权限）
- ✅ 剪贴板粘贴模式（长文本更快）
- ✅ 可调每字间隔 + 随机抖动，模拟人手打字
- ✅ 开始前倒计时，方便切换窗口
- ✅ 随时「停止」中断
- ✅ 全程自动写日志到 exe 同目录的 `运行日志.txt`（含时间戳，出错可查）
- ✅ 打包为单个 `exe` 文件，双击即用

## 使用步骤

1. 双击运行 `代写小助手.exe`
2. 点 **选择文件…** 选一个 TXT 文档
3. 设置输入方式、速度、倒计时
4. 点 **确定并开始** → 趁倒计时把鼠标点进目标输入框
5. 程序自动把文档内容打进输入框；中途可点 **停止** 中断

> 提示：换行默认按「回车」输入；如果目标输入框是单行框、不需要换行，取消勾选「换行按回车输入」即可。

## 目录结构

```
代写小助手/
├── main.py            # GUI 主程序
├── typewriter.py      # 键盘模拟后端（SendInput）
├── requirements.txt   # 打包依赖（仅 PyInstaller）
├── build_exe.bat      # 一键打包脚本
├── README.md
└── dist/              # 打包输出（代写小助手.exe）
```

## 自己打包

需要 Python 3.9+ 与 PyInstaller：

```bat
python -m pip install -r requirements.txt
build_exe.bat
```

或手动执行：

```bat
python -m PyInstaller --onefile --windowed --name "代写小助手" --clean main.py
```

成品在 `dist\代写小助手.exe`。

## 安全说明

- 本工具仅调用系统标准键盘接口，**不联网、不收集任何信息**。
- 杀毒软件可能对 PyInstaller 打包的 exe 误报（常见现象），添加信任即可。
- 请勿用于违反平台规则或侵犯他人权益的用途。
